# تيته — الحلو بتاع زمان

منيو رقمي عربي (RTL) لمحل حلويات **تيته**، مبني mobile‑first.
المحتوى منقول حرفيًا عن المنيو المطبوع (`download.pdf`) — الأصناف والأسعار والمقاسات زي ما هي.

**Teta** — a mobile-first, right-to-left Arabic digital menu for an Egyptian sweets shop.

## اللي فيه

- **منيو كامل** بالأقسام: الشرقي، رز بلبن، ترى ليتشي، الغربي، المخبوزات، التورتة، اضافات.
- **مفتاح المقاس** للحلو الشرقي (طبق / نص كيلو / كيلو) — السعر المختار بيبان كبير وواضح، وباقي المقاسات بتفضل موجودة على الشاشات الأعرض. الاختيار بيتحفظ للزيارة الجاية.
- **تنقّل لاصق** بين الأقسام: شريط تصنيفات أفقي على الموبايل، وفهرس جانبي على الديسكتوب.
- **الفروع** بروابط خرايط، و**زرار اتصال ثابت** في متناول الإبهام.
- هوية بصرية مبنية على اللوجو نفسه: بنفسجي `#85298C`، فوشيا `#ED238B`، قماشة كاروهات، وحواف مسننة زي علبة الحلو.

## التقنية

- [Astro](https://astro.build) — HTML ثابت، من غير أي framework على المتصفح.
- CSS مكتوب بإيد مع طبقة design tokens (`src/styles/global.css`).
- خطوط self-hosted: **Rakkas** للعناوين و**Readex Pro** للنص.
- الصور بتتحوّل WebP أوتوماتيك عن طريق `astro:assets`.

## التشغيل

```bash
npm install
npm run dev      # سيرفر التطوير
npm run build    # بناء للإنتاج في dist/
npm run preview  # معاينة البناء
```

## بيانات المنيو

كل المحتوى في ملف واحد: `src/data/menu.ts`.
أي تعديل في الأسعار بيتعمل من هناك بس.

> **ملحوظة:** سعر الحجم الصغير من «ديسباسيتو / نوتيلا» مطبوع أبيض على وردي في المنيو الأصلي ومش مقروء،
> فبيظهر في الموقع كـ «السعر بالفرع» لحد ما المحل يأكده. مفيش أي سعر متخمّن.

## المصادر

- `logo.jpg` — اللوجو الرسمي، واتسحبت منه ألوان الهوية وعلامة تيته.
